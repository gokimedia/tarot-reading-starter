# Vercel Template Submission

## Prerequisites
1. Push repo to `github.com/gokimedia/tarot-reading-starter` (public)
2. Deploy once to Vercel to verify it works: `vercel deploy`
3. Confirm `https://tarot-reading-starter.vercel.app` renders

## Submit to Vercel Templates Marketplace
1. Go to https://vercel.com/templates/submit (or fork https://github.com/vercel/vercel/tree/main/packages/templates)
2. Required fields:
   - **Title:** Tarot Reading Starter
   - **Description:** Minimal Next.js 16 tarot reading template. 78-card dataset, daily draws, three-card spreads, typed `vercel.ts` config. Powered by Deckaura.
   - **GitHub URL:** https://github.com/gokimedia/tarot-reading-starter
   - **Live Demo:** https://tarot-reading-starter.vercel.app
   - **Framework:** Next.js
   - **Use case:** Content, Entertainment
   - **Author:** Deckaura — https://deckaura.com

## Expected Backlinks
- `vercel.com/templates/nextjs/tarot-reading-starter` — author profile dofollow
- Preview URL on every clone click — indirect indexed links
- **No other tarot template exists in the Vercel marketplace as of April 2026** (verify before submitting)
